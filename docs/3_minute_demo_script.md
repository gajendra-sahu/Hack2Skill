# 3-Minute Demo Script

**0:00–0:25 — Problem.** “Banks manage fraud signals, transaction risk and regulatory obligations across separate systems. Analysts spend time joining data, searching policy and documenting why a case matters. RegIntel 360 brings signal, evidence and documented finding into one governed Snowflake workflow.”

**0:25–0:50 — Data foundation.** Show 5,000 synthetic transactions and 80 synthetic policy/regulatory documents. Explain the injected structuring, rapid-velocity, high-value and high-risk-merchant patterns.

**0:50–1:20 — Risk cockpit.** Open Streamlit. Show transaction count, alert count, high-risk count and pattern distribution. Open one alert and point to transaction ID, customer ID, risk score and explainable rule evidence.

**1:20–2:05 — Cortex Agent.** Ask: “Which customers show structuring behavior, and which policy evidence should an analyst review?” Explain that the Agent can use the semantic view for structured analytics and Cortex Search for document retrieval.

**2:05–2:35 — Evidence-backed finding.** Show transaction IDs plus RI360 document IDs. Emphasize the flow: signal → transaction evidence → policy evidence → analyst finding. State that the bundled documents are synthetic and not legal advice.

**2:35–2:55 — Evaluation.** Run one structured question, one policy search and one hybrid question from the 20-question evaluation set.

**2:55–3:00 — Close.** “RegIntel 360 turns fragmented risk and regulatory evidence into a governed, explainable and audit-ready intelligence workflow inside Snowflake.”
